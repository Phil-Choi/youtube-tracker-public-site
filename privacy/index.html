개인정보처리방침

시행일: 2026년 10월 23일

1. 운영자 및 적용 범위

YouTube Tracker는 Phil Choi / ePartners가 운영하는 개인 자동화 도구입니다. 이 방침은 YouTube Tracker가 Google API를 통해 접근하거나 처리하는 정보와 서비스 운영 중 생성되는 관련 기록에 적용됩니다.

2. 접근하는 정보

  • Google OAuth 인증정보와 Gmail 발송 권한(gmail.send)
  • 발신 Gmail 주소와 관리자가 지정한 수신 이메일 주소
  • YouTube 채널 ID·채널명 및 공개 RSS의 영상 ID·제목·URL·게시 시각
  • 메일 발송 상태, 발송 시각 및 Gmail 메시지 ID
  • 장애 진단에 필요한 제한적인 실행 로그와 모니터링 정보

YouTube Tracker는 Gmail 받은편지함, 연락처 또는 기존 메일 내용을 읽거나 수정·삭제하지 않습니다.

3. 정보 사용 목적

수집·처리되는 정보는 다음 목적에만 사용됩니다.

  • 등록된 YouTube 채널의 새 영상 알림 메일 발송
  • 동일한 영상 알림의 중복 발송 방지
  • 발송 결과 확인, 오류 진단 및 서비스 보안 유지

4. 저장 및 보호

OAuth 토큰은 Google Cloud Secret Manager에 저장됩니다. 채널·영상·수신자별 발송 이력은 Google Cloud Firestore에 저장되며, 실행 로그와 장애 정보는 Google Cloud Logging 및 Monitoring에서 처리됩니다. 접근 권한은 서비스 운영에 필요한 계정과 서비스 계정으로 제한됩니다.

5. 공유 및 판매

Google 사용자 데이터는 판매하거나 광고에 사용하지 않습니다. 서비스 제공에 필요한 Google Cloud와 Gmail API 처리 외에는 제3자와 공유하지 않습니다. 공개 웹페이지는 Vercel에서 호스팅되므로 접속 시 일반적인 요청 로그 등 기술 정보가 Vercel의 방침에 따라 처리될 수 있습니다.

6. 보유 기간 및 삭제

OAuth 인증정보는 권한이 철회되거나 서비스 운영이 종료될 때까지 보관합니다. 발송 이력은 중복 발송 방지와 장애 확인에 필요한 기간 동안 보관합니다. 정보 삭제를 요청하면 법률 또는 보안상 보존이 필요한 경우를 제외하고 관련 정보를 삭제합니다.

7. 권한 철회 및 삭제 요청

Google 계정의 서드 파티 앱 및 서비스 페이지에서 YouTube Tracker의 접근 권한을 언제든지 철회할 수 있습니다. 데이터 열람 또는 삭제 요청은 pendulum.choi@gmail.com으로 보내 주세요.

8. Google API 제한적 사용

YouTube Tracker가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API Services User Data Policy와 Limited Use 요구사항을 준수합니다. 자세한 내용은 Google API Services User Data Policy 를 참고해 주세요.

9. 방침 변경

데이터 처리 방식이 변경되면 이 페이지를 갱신하고 시행일을 수정합니다. 중요한 변경이 있는 경우 서비스 이용자에게 적절한 방법으로 알립니다.
